# Gestão de Gases Medicinais — Serra V4.3

Frontend para GitHub Pages integrado ao Google Apps Script.

## Configuração desta versão

- O endereço do Apps Script já está definido em `js/config.js`.
- Não existe APP_KEY.
- Não existe botão “Configurar API”.
- O acesso utiliza somente usuário e senha configurados nas Propriedades do Script.
- A sessão é temporária e mantida apenas enquanto o navegador permanece aberto.

## Publicação

Envie todo o conteúdo desta pasta para a raiz do repositório GitHub, incluindo as pastas `assets`, `docs` e `js`. Depois confirme o commit e aguarde o GitHub Pages publicar.

O backend está na pasta `02_APPS_SCRIPT` do pacote completo e não deve ser colocado no GitHub.
